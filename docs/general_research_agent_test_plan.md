# General Research Agent, Test Plan

## Test 1, Pest Control Company
- input a real pest control company
- ask for website weakness, pain points, and ROI hooks
- verify the output is short and usable for outreach

## Test 2, Content Factory Topic
- input a content or research topic
- ask for structured facts, opportunities, and risks
- verify the output supports drafting or strategy

## Pass Criteria
- correct facts
- concise output
- useful next steps
- clear uncertainty
- no invented claims

## Fail Criteria
- too verbose
- generic output
- wrong source use
- no clear next action
- made up details
