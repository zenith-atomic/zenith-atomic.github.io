# Pest Control Outreach System

## Goal
Book discovery calls with pest control owners by showing them where revenue is leaking.

## Core Message
You are losing jobs from missed calls, stale quotes, and weak follow-up. We fix that.

## Channels
- email
- calls
- follow-up SMS
- manual direct messages if appropriate

## Flow
1. identify target
2. send short personalized outreach
3. call after no response
4. follow up again
5. book call
6. show revenue recovery demo

## Outreach Themes
- missed calls
- quote follow-up
- review requests
- old lead reactivation
- weak web / booking flow

## Cadence
- day 1 email
- day 2 call
- day 4 follow-up
- day 7 follow-up
- day 10 final bump

## Reply Handling
- if interested, book call
- if not now, ask for later date
- if no reply, move to follow-up queue
- if wrong person, ask for owner or office manager
