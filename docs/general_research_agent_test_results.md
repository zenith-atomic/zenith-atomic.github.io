# General Research Agent, Test Results

## Test 1, Pest Control
### Input
Research a pest control company for outreach.

### Result
- output should identify website weakness
- output should surface revenue recovery hooks
- output should stay short
- output should help a draft agent write a focused email

### Notes
- strong output must mention missed calls, quote follow-up, or review flow
- should not include filler about the entire industry

## Test 2, Content Factory
### Input
Research a general topic for content or strategy.

### Result
- output should isolate the useful facts
- output should expose opportunity and risk
- output should remain structured
- output should support downstream drafting

### Notes
- the agent works best when the target is specific
- it should flag uncertainty instead of guessing

## Test 3, Live Pest-Control Smoke Test
### Input
Research Cross Pest Control of Tampa, Turner Pest Control, and Anti-Pesto Bug Killers for outreach.

### Result
- output stayed short and usable
- output surfaced likely revenue levers
- output separated stronger brands from smaller/local opportunities
- output was good enough for next-step outreach drafting

### Notes
- best hooks were missed-call recovery, quote follow-up, and speed-to-lead
- no outbound email was sent
