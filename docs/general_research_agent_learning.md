# General Research Agent, Learning Log

## Lesson Format
- date
- task
- what worked
- what did not
- what to reuse
- what to avoid

## Update Rule
After a task completes, append one short lesson if it produced a real improvement.

## Examples of Good Lessons
- official source X is faster than broad web search
- short briefs outperform long ones for decision-making
- lead qualification is stronger when websites and profiles are checked before outreach
- structured output makes downstream drafting easier
- smoke tests should end with a dashboard update and a clear next action
- outbound email must remain approval-gated
