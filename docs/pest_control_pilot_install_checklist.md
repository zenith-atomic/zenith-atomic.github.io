# Pest Control Pilot Install Checklist

## 1. Pre-Install
- Confirm target niche
- Confirm business name and service area
- Confirm who receives leads
- Confirm phone number used for missed-call recovery
- Confirm review link
- Confirm follow-up windows
- Confirm compliance / opt-in language

## 2. Data Collection
- business name
- primary phone
- backup phone
- email(s)
- service areas
- lead categories
- quote follow-up rules
- review link
- old lead CSV, if available

## 3. Workflow Setup
- missed-call text back enabled
- web lead capture enabled
- quote follow-up sequence loaded
- review request sequence loaded
- reactivation sequence loaded
- owner notifications turned on

## 4. Templates
- initial missed-call reply
- quote follow-up 1
- quote follow-up 2
- quote follow-up 3
- review request
- reactivation message

## 5. Dashboard
- leads received
- leads contacted
- replies
- booked jobs
- pending quotes
- review requests sent
- reactivated leads

## 6. Testing
- test a missed call
- test a form submission
- test a quote follow-up
- test a review request
- test dashboard logging
- test pause / override

## 7. Go-Live
- turn on live sequences
- verify notifications
- verify owner understands the flow
- start daily monitoring

## 8. 7-Day Review
- count leads recovered
- count replies
- count booked jobs
- count reviews requested
- note any failures
- tighten templates

## 9. Client Handoff
- summary of what is live
- login / access list
- support contact
- template copy
- next steps
