### Post 10 — LinkedIn — Carousel Doc

**Pillar:** Tool Reviews & Tutorials  
**Format:** Carousel doc  
**Hook Style:** Bold claim

#### Hook Variant A
**A verified local lead is more valuable than a massive unverified list.**

**Doc outline:**
1. Define one niche and one location
2. Pull map results
3. Cross-check directories
4. Verify live website presence
5. Exclude ambiguous entries
6. Score by confidence
7. Build a usable outreach list

**Why this works:**
It cuts wasted outreach, reduces false positives, and keeps the process repeatable.

Most agencies don’t have a lead-gen problem.
They have a verification problem.

#### Hook Variant B
**The fastest way to improve local prospecting is not more data. It’s better filtering.**

Use this checklist:
- Search one clear query
- Validate across sources
- Confirm no live website
- Remove anything uncertain
- Keep only confident matches

That’s how you build a list you can actually use.

#### Hook Variant C
**Lead-gen gets easier when you stop trusting first-pass data.**

The workflow:
- Search
- Cross-check
- Verify
- Exclude
- Score
- Outreach

Simple. Boring. Effective.
