#### Hook Variant A
**Most "no-website business" research fails because it trusts the first source.**  
Here's the verification playbook that actually works:

1/ Pull the Google Business Profile.
Check the website field first. If it's blank, that's a signal — not a conclusion.

2/ If the API blocks you, pivot to directories.
Businessrate.com, MapQuest, Manta. Each confirms or denies independently.

3/ Cross-reference for confidence.
Two sources agree: high confidence. One source only: partial. Walk away from ambiguous.

4/ Log the exclusion reasons.
Every "no" tells you something. "Has a site" is a no. "Website exists but is terrible" is still a no.

5/ Set a confidence threshold and hold it.
Most people fail here. They lower the bar when the list looks thin. Don't.

6/ The output is not a list of businesses.
It's a list of verified opportunities with a reason attached to each.

That's the playbook.

**The reusable version:**
- Google Business Profile → website field check
- businessrate.com → explicit website presence
- MapQuest → secondary confirmation
- Manta → industry classification cross-check
- BuildZoom → license/permit verification (optional, high confidence)

Confidence scale: 1 source = partial. 2+ sources = high. Excluded = logged.

That's it. No magic. No API dependency. No rate limit vulnerability.

#### Hook Variant B
**A reusable framework for finding no-website businesses without API access.**  
Thread:

1/ Start with Google Business Profile if you have access.
Website field blank = signal.

2/ Directory pivot when blocked.
Businessrate.com, MapQuest, Manta — each gives explicit presence/absence data.

3/ Two-source rule.
One source = partial. Two agree = high confidence. Don't use anything below your threshold.

4/ Log exclusions, not just accepts.
"Has website" is data. "Site exists but bad" is data. "Ambiguous" is a reason to exclude.

5/ The artifact is a scored list.
Business, address, phone, source count, confidence level, exclusion reason.

Repeatable. No API dependency. No scraping required.
