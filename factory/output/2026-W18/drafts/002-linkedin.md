#### Hook Variant A
Got rate-limited 6 times running Google Business Profile lookups this week.

Here's what I did instead — and why it actually worked better.

When Gemini API started throwing 429s and 503s, I pivoted to business directories. Specifically: businessrate.com, MapQuest, Manta, and BuildZoom.

Why directories actually work for this use case:

1. Directory listings explicitly state whether a business has a website. No inference needed.

2. They update slower, which means they catch businesses that never invested in a web presence — exactly the target.

3. They don't rate-limit you the same way an API does.

The result: Duct Path Cleaners, Tampa FL. Verified no-website. Phone and address confirmed through two sources.

That's the lead that survived the wall.

The workaround found what the direct approach couldn't.

Practical takeaway: when your primary data source blocks you, directories aren't a backup. For this specific vertical, they're the primary source.

#### Hook Variant B
This week I learned something counterintuitive:

The directory approach beats direct scraping for finding no-website businesses.

Here's why.

Google Business Profile API gives you the website field directly — but it rate-limits fast, throws 503s when you're not ready, and requires access you may not have.

Directories (businessrate.com, MapQuest, Manta) tell you explicitly whether a site is listed. They're slower to update, which is actually a feature when you're hunting for businesses that never went digital. And they don't hammer you with rate limits.

I got blocked. I switched. I found Duct Path Cleaners in Tampa — verified no-website, confirmed across two sources.

The workaround was the product.

If you're running this kind of research and hitting walls, try the directory pivot before you scale up your API setup.
