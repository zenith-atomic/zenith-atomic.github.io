# Tool Guidance — Analytics Agent

## web_search / web_fetch
Use only to find industry benchmarks to contextualize the data:
- "average engagement rate [platform] [niche] 2026"
- "benchmark [content format] performance [platform]"
- "industry standard impressions [content type]"

Do not search for general analytics advice. Base all recommendations on the provided KPI data.

Not needed — all context arrives in the task message.
