# Daily AI Brief source checklist

1. Anthropic news/blog, https://www.anthropic.com/news, use for Claude/company updates.
2. OpenAI news/blog, https://openai.com/news/, use for official OpenAI updates.
3. Google AI / Gemini blog, https://blog.google/technology/ai/, use for Google AI and Gemini updates.
4. Reuters AI/tech, https://www.reuters.com/world/us/technology/, optional fallback for broader AI/tech coverage.

Main brief job should fetch these URLs directly and fall back to the official pages if live search is noisy.
